# 1.3 企业质量工作台

## 界面布局

- 顶部：项目名称、黄金集/真实模型模式、主要操作。
- 中部：需求、TAD、测试用例、接口规格、Web ATC、反馈、证据和运行日志。
- 右侧“流程”：六阶段导航、独立生成、产物查看与阶段状态。
- 右侧“配置”：输入来源、HTTP/Dubbo 目标、输出路径、项目工作区初始化。
- 底部：运行状态、当前产物路径和“打开产物”。

宽窗口使用双栏。窄窗口默认保留编辑区，点击“流程与配置”切换完整流程面板，点击“收起”返回；资产标签可横向滚动。生成期间禁用重复启动和配置编辑。

## 原生主题与操作

界面使用 Swing 与 IDEA 组件，不加载网页。颜色读取当前主题，按钮提供悬停、焦点和禁用状态，常用操作保留键盘访问。模型设置将黄金集与网关配置分组，黄金集开启时网关字段暂不可编辑。

## 安装与验证

安装 `dist/ai-test-flow-idea-plugin-1.3.0.zip` 后重启 IDEA。进入右侧 AI Test Flow → 质量工作台。

1. 点击“黄金集 Demo”，确认右上角显示“黄金集演练”。
2. 点击“运行完整链路”，观察六阶段状态及底部产物路径。
3. 在流程面板点击“查看”浏览对应资产；接口自动化步骤打开生成清单。
4. 在配置面板调整接口目标与路径，在顶部“模型设置”统一配置模型。

黄金集、Git 项目资产管理和覆盖保护继续沿用。未提供真实执行日志时，反馈保留 blocked / not-run。

## 验证范围

测试覆盖流程导航、忙碌时禁止重复启动、错误状态、440px 窄窗口、双栏及深浅配色组件渲染。组件截图输出在 `build/ui-preview/`，用于布局检查；IDEA 最终效果使用其原生主题和字体。
