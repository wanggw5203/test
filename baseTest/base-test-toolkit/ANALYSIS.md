# 原测试基础库分析

原始 JAR 是一个综合测试基础库，共包含约 245 个类，构建目标为 Java 21。其主要能力可归纳为：

- Spring/TestNG 测试基类和监听器。
- YAML、JSON、JSON5 数据驱动和参数类型转换。
- JSON 严格或宽松字段比较。
- 本地及远程环境配置、数据库和中间件连接配置。
- 用户认证、账号上下文和固定令牌处理。
- HTTP/RPC Mock 场景管理。
- 配置中心、服务治理、任务调度和数据工厂客户端。
- 覆盖率上报、调用日志收集和 HTML 测试报告。
- 大量平台请求及响应模型。

新工程保留配置加载、数据驱动、类型转换、JSON 比较、测试上下文和基础模型，并重新实现为中性 API。以下能力因依赖专用基础设施或包含组织特有约定而排除：

- 内部包名、Maven 坐标、域名和静态资源地址。
- 内部认证、员工账号、固定令牌和网关逻辑。
- 内部配置中心、服务治理、数据工厂和任务平台客户端。
- 内部 Mock 服务、覆盖率上报和调用日志平台。
- 内部环境、机房、泳道、项目和中间件命名约定。
- 依赖企业 Starter 的自动配置和敏感连接配置解密。

该处理不是对原始字节码逐类改包，而是按公开 API 和实际使用方式重新实现通用子集，避免把隐藏的平台依赖和组织约定带入新产物。
